# ほうにゃんスタンプ台帳

特別支援のプリント取り組みを、児童ごとにスタンプシートで管理するローカルWebアプリです。`index.html`をブラウザで開いて使います。従来型のJavaScriptと静的ファイルで構成しており、ビルド工程やnpmパッケージは不要です。

## 主な機能

- 児童ページと先生ページの分離、通常学級・特支学級の年度別の二重所属と所属履歴
- 20個で1シートのスタンプ経済、1回最大100個の一括押印、累計スタンプによる20段階のほうにゃんレベル
- 購入専用スタンプの児童別所有チェック、購入取消時の所有状態の整合、ショップ・スタンプセット・ずかん
- 手動判定と自動判定のデイリーミッション、きっぷ報酬、テスト児童フラグ、先生による進捗調整
- 年度、クラス、教科、適用期間つき時間割、日付ごとの時間割変更、学校予定、登校日・休業日判定
- タイマー、押印・シート完成・レベルアップの演出、JSON書き出しと自動バックアップ

## ミッションの自動条件

現在自動連携しているのは、通常のスタンプ押印イベントを基にした「プリント完了枚数」と「スタンプ獲得数」です。現状の自動基準値は両条件とも通常のスタンプイベント数を使います。

「問題を解いた数」「正解数」「連続正解数」「学習時間」は、アプリ内の学習イベント契約とは接続していません。これらを自動達成として扱わず、先生の進捗調整・判定または将来の学習イベント連携で補います。

## 完成シートの印刷

児童ページの「シートをみる」から、がんばりアルバムを開きます。
各シートの「このシートを印刷」、または「全部のシートを印刷」で印刷できます。
完成済みの20個を児童名・完成日時付きでA4縦1ページに配置します。全部印刷は1枚目から順番です。
印刷画面では用紙をA4、倍率を100%にし、ブラウザのヘッダーとフッターをオフにしてください。
「PDFに保存」も利用できます。印刷してもスタンプや交換残高は変わりません。

## 保存と復元

- 主データは`hounyan-stamp-ledger-v1`に保存し、主書き込みをトランザクション境界として扱います。容量不足・保存権限エラー時は、主データと画面上の業務状態を直前の保存済み状態へ戻し、成功表示・フォーム消去・報酬演出を実行しません。再試行できます。
- 起動時に保存データを読めない場合は安全な初期状態を表示しますが、「保存不可」を明示して通常の上書き保存を止めます。壊れた主データの原本を保護できた場合だけ、有効なJSONによる復旧を受け付けます。読み込み失敗時の旧`BACKUP_STORAGE_KEY`原本は、既存値を消したり上書きしたりせず保持します。
- JSON読み込み・自動バックアップ復元は、候補を検証・正規化してから「現在の台帳を置き換える」確認を表示します。ルート、必須配列、null、重複ID、有限でない数値、現行設定で表示に影響する参照不整合を検出し、キャンセル・検証失敗・ファイル読み込み失敗・事前バックアップ失敗・主書き込み失敗のいずれでも現在データを維持してファイル入力をリセットします。
- 新規書き出しはスキーマ情報付きの形式です。過去の状態JSONも読み込めます。自動バックアップは最大6件の全状態を保存します。主データ保存後の自動バックアップだけが失敗した場合は主データを戻さず、今回の変更がバックアップへ未反映であることを警告します。

大切な節目では、先生ページの「JSONを書き出す」でファイルにも残してください。保存先はこのPCのブラウザ内です。

## カレンダー・時間割

- 年度の追加と現在年度の切り替え
- クラスの追加、編集、有効・無効、並び替え、完全削除
- 同じ児童を年度ごとに別の学年・クラスへ所属させ、過去の所属履歴を保持
- クラスごとの月曜から金曜・最大10時間の基本時間割、適用開始日・終了日、別クラスへのコピー
- 教科の追加、編集、有効・無効、月間カレンダー、学校全体またはクラス別の予定
- 休業日、土曜授業、短縮授業、行事日の登校日判定、日付ごとの一部時間割変更

年度、クラス、児童の所属履歴、予定、時間割、スタンプ履歴、ミッション、報酬はJSONに含まれます。日本の祝日は端末内で判定し、学校予定の「登校日への影響」で上書きできます。
